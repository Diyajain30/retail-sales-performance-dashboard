# Retail Sales Performance Dashboard

An end-to-end data analytics project analyzing 9,000+ retail transactions from the Superstore dataset to track financial KPIs, regional performance, and customer segment trends.

## Tech Stack
- **Database / SQL:** MySQL (Data staging, typing, and baseline aggregation queries)
- **Business Intelligence:** Microsoft Power BI (Power Query, DAX, Interactive Dashboard)
- **Data Inspection:** Microsoft Excel

## Project Structure
- \data/raw/\: Raw transactional dataset
- \sql/\: DDL scripts, data audit checks, and KPI queries
- \powerbi/\: Power BI report file (.pbix)
- \images/\: Visual architecture and dashboard screenshots
